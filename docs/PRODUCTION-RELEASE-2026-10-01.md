## عائق Preview وقرار النشر

بناء Preview نجح، لكن فحصه لم ينجح. الطلب البعيد عاد HTTP 302 إلى `https://vercel.com/sso-api` قبل الوصول إلى التطبيق. الجهاز المحلي حلّ DNS واتصل بمنفذ TCP 443، لكن TLS على رابط vercel.app فشل على العنوانين اللذين أعادهما DNS. Chromium وFirefox انتهيا بمهلة، وWebKit بخطأ SSL، وChrome وBrave أظهرا ERR_CONNECTION_RESET. الدومين الإنتاجي وvercel.com وGitHub نجحت اتصالات TLS بها.

لم يتوفر اعتماد Vercel CLI أو جلسة Vercel مصادق عليها. لم نطلب كلمات مرور أو Tokens ولم نعطّل Deployment Protection. الأدلة لا تثبت السبب النهائي داخل الشبكة أو الجهاز. صاحب المشروع وافق صراحة على النشر مع تجاوز شرط فحص Preview بعد هذا التشخيص؛ لا نسجل Preview باعتباره ناجحًا.
