The government archive date shows the civil day without a time. The pipeline conservatively assigns 00:00 Asia/Amman and starts its 48-hour window there. A later site modification date never renews freshness. Only a small attributed passage and original title/link are stored; no full article is republished.

## Reference and live checks

`npm run news:historical-replay` fetches eight real official detail pages dated 9–29 September, applies the pipeline at publication date +24 hours, and prints each extracted event and stage. It replays each day through the ingestion path in a disposable local replica set, then repeats identical input. The latest run created eight candidates and **30 events**: 28 eligible at the simulated time, two routine exclusions, eight repeated candidate duplicates, zero public items. All six positive articles and both negative articles matched manual labels. The 9 September park directive is now extracted from the official detail heading (`<title>` is 237 characters, the detail heading 140). The 17 September Cabinet bulletin has 57 parsed paragraphs and 12 evidenced action events; the 20 September bulletin has nine, including one body-only personnel decision; the 27 September bulletin has four. The three bulletins use separate operative headings, with one combined heading split only where it explicitly states two different stages. Jointly announced systems stay grouped without independent evidence.

`npm run news:live-replay` fetched the four live entries into a disposable local MongoDB replica set on 30 September at 03:21 UTC: 55 source materials, 55 candidates, 67 events, one eligible event, zero public items. The other 66 events were 34 without a verified action (all from media feeds), one outside civic scope (a restaurant item), and 31 older than 48 hours (22 Prime Ministry events, nine Ministry of Labour). Identical second input yielded 55 duplicate candidates and zero new ones. The shadow selection dry run chose zero; `currentBatchId` stayed null. Date-only government cards are conservatively aged from 00:00 Jordan time. These counts describe the observed entry pages only; the test database is destroyed after the run.

## Deployed Preview follow-up

On 30 September, actual Vercel Discovery read ten Prime Ministry and ten Ministry of Labour materials without source/detail errors. Roya returned 25 entries. Al Mamlaka returned HTTP 403 from Vercel in each actual deployed run, while its RSS remained accessible from the local network. This is recorded as a deployed coverage gap; no challenge or authentication bypass was attempted. All Preview database tests used a dedicated readWrite@nashmi_preview credential after native runtime isolation verification.
